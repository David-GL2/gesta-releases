Características

Todo lo que necesitas para organizarte

Las funciones importantes están aquí. Sin herramientas innecesarias ni menús complicados.

TAREAS

Gestión completa

Crea, edita y elimina tareas fácilmente. Márcalas como completadas cuando hayas terminado. La app te marcará las tareas que se pasen de fecha!

ORGANIZACIÓN

Categorías basicas

Organiza tus tareas utilizando las categorias predefinias: sin categoria, trabajo, estudios, personal, dieta, rutina, otros. Añade fechas limite o no!

BÚSQUEDA

Busca y filtra

Encuentra rápidamente tareas por título, categoría, estado(todas, pendientes o completadas) o fecha.

DATOS

Almacenamiento local

Tus tareas se almacenan localmente en un archivo JSON en la carpeta Dcoumentos de tu usuario. Tu tienes el control de tu información personal.

EXPORTACIÓN

Exporta tus tareas

Exporta tus tareas a CSV o PDF para conservar una copia, analizar tus datos o incluso llevar un registro de tu dieta, entrenamientos y otros objetivos personales. Usa GesTa también como una pequeña base de datos personal.

DISEÑO

Modo oscuro - Minimalista

Una interfaz oscura, limpia y pensada para utilizarse cómodamente en el escritorio.

Un vistazo

Así se ve por dentro

Una interfaz sencilla para que puedas concentrarte en tus tareas y no en aprender a utilizar la aplicación.

PRINCIPAL

Todas tus tareas

Visualiza y gestiona tus tareas desde una única pantalla.

CREAR

Crea nuevas tareas

Añade toda la información que necesitas de forma rápida y sencilla.

DETALLE

Información de cada tarea

Consulta todos los detalles de una tarea de forma clara y ordenada.

Haz clic en cualquier captura para ampliarla.
