Política de Privacidad

Última actualización: 19 de agosto de 2026

GesTa es una aplicación de escritorio para Windows diseñada para gestionar tareas de forma local. Esta política explica cómo se manejan los datos cuando utilizas la aplicación.

1. Datos que recopilamos

No recopilamos ningún dato personal. GesTa no solicita ni almacena información como nombres, correos electrónicos, direcciones IP o datos de ubicación.

2. Almacenamiento local

Las tareas que creas en GesTa se almacenan localmente en un archivo tasks.json dentro de la carpeta de la aplicación.

Este archivo permanece en el equipo del usuario y no se envía a ningún servidor externo.

3. Servicios de terceros

GesTa no utiliza servicios de terceros destinados a recopilar datos de los usuarios.

La aplicación no incluye sistemas de analítica de comportamiento, publicidad ni herramientas de seguimiento.

4. Conexión a Internet

GesTa está diseñada para funcionar de forma local y no requiere una conexión permanente a Internet para gestionar tus tareas.

La aplicación puede requerir conexión a Internet durante el proceso de adquisición o verificación de la licencia a través de Microsoft Store, dependiendo del funcionamiento de la plataforma.

5. Seguridad

Tus tareas se almacenan localmente en tu propio equipo. GesTa no realiza copias de estos datos en servidores externos.

El usuario es responsable de mantener protegido su dispositivo y realizar las copias de seguridad que considere necesarias.

6. Exportación de datos

GesTa permite exportar la información de tus tareas a formatos como CSV o PDF.

Estas exportaciones se realizan localmente y permanecen bajo el control del usuario.

7. Contacto

Si tienes alguna pregunta relacionada con esta política de privacidad, puedes contactar con el desarrollador a través de los canales oficiales asociados a GesTa, incluyendo la Microsoft Store o el repositorio oficial de GitHub.

8. Cambios en esta política

Esta política puede actualizarse ocasionalmente para reflejar cambios en la aplicación o en sus características. Cualquier modificación será publicada en esta página junto con una nueva fecha de actualización.
